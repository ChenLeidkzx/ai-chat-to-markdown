# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch. Older versions may not receive fixes.

## Reporting a vulnerability

Please do not report exploitable security issues in public issues. Use GitHub's **Report a vulnerability** feature on this repository to submit a private report. Include the affected version, reproduction steps, and impact where possible.

The extension is designed to process conversation content locally and should not transmit conversation data. Do not include real private conversations, credentials, or API keys in a report; use a minimal reproducible example.
